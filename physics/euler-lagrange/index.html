    Euler-Lagrange equations: A derivation

    Diptanuj Sarkar
    January 13, 2024

    Introduction

    We start off by taking as a prototype the simple Newtonian scheme of a point particle of mass mmm moving along the x-axis under a potential field V(x)V(x)V(x).

    According to Newton’s Second Law of motion,

    md2xdt2=−dVdx m \frac{d^2 x}{dt^2} = - \frac{dV}{dx} mdt2d2x​=−dxdV​

    If we are given the position and the velocity of this particle at some initial time, i.e. x(ti)x(t_i)x(ti​) and x˙(ti)\dot{x}(t_i)x˙(ti​), then it is possible for us to compute the classical trajectory of the particle xcl(t)x_{cl}(t)xcl​(t) as follows

    xcl(t+Δt)=x(ti)+x˙(ti)Δt x_{cl}(t+\Delta t) = x(t_i) + \dot{x}(t_i) \Delta t xcl​(t+Δt)=x(ti​)+x˙(ti​)Δt

    We can keep following the same iteration scheme to calculate the position at t+2Δtt+2\Delta tt+2Δt, t+3Δtt+3\Delta tt+3Δt, and so on.

    Since the equation of motion is second order in time, there are two pieces of data (namely, x(ti)x(t_i)x(ti​) and x˙(ti)\dot{x}(t_i)x˙(ti​)) that are required to specify a unique xcl(t)x_{cl}(t)xcl​(t). An equivalent way to doing the same thing is to specify an initial point (xi,ti)(x_i,t_i)(xi​,ti​) and a final point (xf,tf)(x_f,t_f)(xf​,tf​) (Why?).

    In the Lagrangian formalism, the same problem is posed in this way: Given the initial and the final point, what is it that distinguishes the actual classical trajectory joining these point from the infinite other trajectories that join these two points? The answer to this lies in the following points:

    • Define a function L\mathbf{L}L, called the Lagrangian which is given by,

      L=T−V \mathbf{L} = T - V L=T−V

      TTT and VVV being the kinetic and potential energies of the particle. Thus, L=L(x,x˙)\mathbf{L} = \mathbf{L}(x,\dot{x})L=L(x,x˙). Note that we assume the absence of ttt dependence by considering a potential field that is not time-dependent.

    • For each path x(t)x(t)x(t) connecting (xi,ti)(x_i,t_i)(xi​,ti​) and (xf,tf)(x_f,t_f)(xf​,tf​), calculate the action, defined by,

      S[x(t)]=∫titfL(x,x˙)dt S[x(t)] = \int_{t_i}^{t_f} \mathbf{L}(x,\dot{x}) dt S[x(t)]=∫ti​tf​​L(x,x˙)dt

      There are square brackets because we want to remember that the argument of S is the entire path or the entire function x(t)x(t)x(t), not just the value of the function at some time. SSS is thus also called a functional.

    • Principle of Least Action: The classical path is the one on which SSS is a minimum (Actually, it is only required that it be an extremum. The name is merely customary).

    Now, we verify whether this principle gives us back Newton’s Second Law.

    A multivariable detour

    Since SSS is a function of some other function x(t)x(t)x(t), it is really just a multivariable function of nnn variables as n→∞n\rightarrow \inftyn→∞. This is due to the fact that the function x(t)x(t)x(t) actually specifies an infinite number of values x(ti),…,x(t),…,x(tf)x(t_i), \dots , x(t) , \dots , x(t_f)x(ti​),…,x(t),…,x(tf​) - one for each instant in time ttt in the specified interval. We will deal with the entire minimum (actually, extremum) situation of the action by generalising how we deal with it in n variables. Let us define a function,

    f=f(x1,…,xn)=f(x⃗) f = f(x_1, \dots , x_n) = f(\vec{x}) f=f(x1​,…,xn​)=f(x)

    The minimum of this function, say, x0⃗\vec{x^0}x0 is characterised by the fact that if we move away from it by a small amount η⃗\vec{\eta}η​ in any direction, the first order change in fff vanishes. Using the Taylor expansion,

    f(x0⃗+η⃗)=f(x0⃗)+∑i=1n∂f∂xi∣x0⃗ηi+ higher order terms in η f(\vec{x^0}+\vec{\eta}) = f(\vec{x^0}) + \sum_{i=1}^{n} \frac{\partial f}{\partial x_i} \bigg\rvert_{\vec{x^0}} \eta_i + \text{ higher order terms in } \eta f(x0+η​)=f(x0)+i=1∑n​∂xi​∂f​​x0​ηi​+ higher order terms in η

    then, we get,

    δf(1)=∑i=1n∂f∂xi∣x0⃗ηi=0 \delta f^{(1)} = \sum_{i=1}^{n} \frac{\partial f}{\partial x_i} \bigg\rvert_{\vec{x^0}} \eta_i = 0 δf(1)=i=1∑n​∂xi​∂f​​x0​ηi​=0

    as the first order change vanishes. From this, we can see that if we choose η⃗\vec{\eta}η​ such that it is along the ith direction, every first order partial derivative of the function vanishes at x0⃗\vec{x^0}x0.

    ∂f∂xi∣x0⃗=0,i=1,…,n \frac{\partial f}{\partial x_i} \bigg\rvert_{\vec{x^0}} = 0 \quad , i = 1,\dots , n ∂xi​∂f​​x0​=0,i=1,…,n

    Coming back to the action

    We now use the property that we deduced to arrive at the extremum of SSS. We assume that xcl(t)x_{cl}(t)xcl​(t) is the path of least action (as per the principle), and that xcl(t)+η(t)x_{cl}(t) + \eta(t)xcl​(t)+η(t) is a “nearby” path. As all the paths have to coincide at the initial and the final points, we get the condition,

    η(ti)=η(tf)=0 \eta(t_i) = \eta(t_f) = 0 η(ti​)=η(tf​)=0

    So now we get to the main attraction,

    S[xcl(t)+η(t)]=∫titfL(xcl(t)+η(t),x˙cl(t)+η˙(t))dt S[x_{cl}(t) + \eta(t)] = \int_{t_i}^{t_f} \mathbf{L} (x_{cl}(t) + \eta(t),\dot{x}_{cl}(t) + \dot{\eta}(t)) dt S[xcl​(t)+η(t)]=∫ti​tf​​L(xcl​(t)+η(t),x˙cl​(t)+η˙​(t))dt

    Now, expanding the Lagrangian to its Taylor series expression,

    ⇒S[xcl(t)+η(t)]=∫titf[L(xcl(t),x˙cl(t))+∂L∂x(t)∣xcl⋅η(t)+∂L∂x˙(t)∣xcl⋅η˙(t)+⋯]dt \Rightarrow S[x_{cl}(t) + \eta(t)] = \int_{t_i}^{t_f} \bigg[ \mathbf{L} ( x_{cl}(t), \dot{x}_{cl}(t) ) + \frac{\partial \mathbf{L}}{\partial x(t)} \bigg \vert _{x _{cl} } \cdot \eta(t) + \frac{\partial \mathbf{L}}{\partial \dot{x}(t)} \bigg \vert _{x _{cl} } \cdot \dot{\eta}(t) + \cdots \bigg] dt ⇒S[xcl​(t)+η(t)]=∫ti​tf​​[L(xcl​(t),x˙cl​(t))+∂x(t)∂L​​xcl​​⋅η(t)+∂x˙(t)∂L​​xcl​​⋅η˙​(t)+⋯]dt⇒S[xcl(t)+η(t)]=S[xcl(t)]+δS(1)+ higher order terms  \Rightarrow S[x_{cl}(t) + \eta(t)] = S[x_{cl}(t)] + \delta S^{(1)} + \text{ higher order terms } ⇒S[xcl​(t)+η(t)]=S[xcl​(t)]+δS(1)+ higher order terms 

    Since this is the case with infinite variables, the sum involving the first order partial derivatives of the action has been converted into an integral. Using the fact that we deduced earlier regarding the first order change going to zero, we can say,

    0=δS(1)=[∂L∂x(t)∣xcl⋅η(t)+∂L∂x˙(t)∣xcl⋅η˙(t)]dt 0 = \delta S^{(1)} = \bigg[ \frac{\partial \mathbf{L}}{\partial x(t)} \bigg \vert _{x _{cl} } \cdot \eta(t) + \frac{\partial \mathbf{L}}{\partial \dot{x}(t)} \bigg \vert _{x _{cl} } \cdot \dot{\eta}(t) \bigg] dt 0=δS(1)=[∂x(t)∂L​​xcl​​⋅η(t)+∂x˙(t)∂L​​xcl​​⋅η˙​(t)]dt

    If we integrate the second term by parts with the partial derivative as the first function and the η˙\dot{\eta}η˙​ term as the second function (Why? It has η˙(t)\dot{\eta}(t)η˙​(t), and we know that η\etaη cancels out at the ends) we get:

    ∂L∂x˙(t)∣xcl⋅η(t)∣titf−∫titf[ddt∂L∂x˙(t)]xcl⋅η(t)dt \frac{\partial \mathbf{L}}{\partial \dot{x}(t)} \bigg \vert _{x _{cl} } \cdot \eta(t) \bigg \vert _{t_i}^{t_f} - \int _{t_i} ^{t_f} \bigg[ \frac{d}{dt} \frac{\partial \mathbf{L}}{\partial \dot{x}(t)} \bigg] _{x _{cl} } \cdot \eta(t) dt ∂x˙(t)∂L​​xcl​​⋅η(t)​ti​tf​​−∫ti​tf​​[dtd​∂x˙(t)∂L​]xcl​​⋅η(t)dt

    As mentioned before, the first term here vanishes. So, we get:

    0=δS(1)=∫titf[∂L∂x(t)−ddt∂L∂x˙(t)]xcl⋅η(t)dt 0 = \delta S^{(1)} = \int _{t_i} ^{t_f} \bigg[ \frac{\partial \mathbf{L}}{\partial x(t)} - \frac{d}{dt} \frac{\partial \mathbf{L}}{\partial \dot{x}(t)} \bigg] _{ x _{cl} } \cdot \eta(t) dt 0=δS(1)=∫ti​tf​​[∂x(t)∂L​−dtd​∂x˙(t)∂L​]xcl​​⋅η(t)dt

    Here, the integral and the stuff inside the bracket acts like the infinite analogue of the sum of all the first order partial derivatives of the multivariable function, i.e. the discrete variable η\etaη is replaced by η(t)\eta(t)η(t), the sum over iii is replaced by the integral over &t&, and ∂f∂xi\frac{\partial f}{\partial x_i}∂xi​∂f​ is replaced by ∂L∂x(t)−ddt∂L∂x˙(t)\frac{\partial \mathbf{L}}{\partial x(t)} - \frac{d}{dt} \frac{\partial \mathbf{L}}{\partial \dot{x}(t)}∂x(t)∂L​−dtd​∂x˙(t)∂L​. Since η(t)\eta(t)η(t) is arbitrary, we may extract the analogue of the finite case:

    [∂L∂x(t)−ddt∂L∂x˙(t)]xcl(t)=0 for ti≤t≤tf \bigg[ \frac{\partial \mathbf{L}}{\partial x(t)} - \frac{d}{dt} \frac{\partial \mathbf{L}}{\partial \dot{x}(t)} \bigg] _{x _{cl} (t) } = 0 \quad \text{ for } t_i \leq t \leq t_f [∂x(t)∂L​−dtd​∂x˙(t)∂L​]xcl​(t)​=0 for ti​≤t≤tf​

    This is the famous Euler Lagrange equation.

    Does this give back NLM?

    If we feed into the equation,

    L=T−V \mathbf{L} = T - V L=T−VT=12mx˙2 T = \frac{1}{2} m \dot{x} ^2 T=21​mx˙2V=V(x) V = V(x) V=V(x)

    Then we get,

    ∂L∂x˙=∂T∂x˙=mx˙ \frac{\partial \mathbf{L}}{\partial \dot{x}} = \frac{\partial T}{\partial \dot{x}} = m \dot{x} ∂x˙∂L​=∂x˙∂T​=mx˙

    and

    ∂L∂x=−∂V∂x \frac{\partial \mathbf{L}}{\partial x} = - \frac{\partial V}{\partial x} ∂x∂L​=−∂x∂V​

    and so the Euler-Lagrange equation becomes Newton’s Second Law for this case,

    ddt(mx˙)=−∂V∂x \frac{d}{dt} (m \dot{x}) = - \frac{\partial V}{\partial x} dtd​(mx˙)=−∂x∂V​

    and we are done!
